🩺 Rempla'IDEL - Mode d'emploi
Rempla'IDEL est une application web progressive (PWA) conçue spécifiquement pour les infirmières libérales remplaçantes. Elle vous permet de gérer votre planning, vos finances, vos kilomètres et même vos tournées de soins, le tout de manière 100% confidentielle et hors-ligne.

Rempla'IDEL

🔒 Confidentialité avant tout
Vos données ne quittent jamais votre appareil. Tout est stocké localement dans le cache de votre navigateur (LocalStorage). Aucune donnée patient nominative n'est demandée.

📱 Comment installer l'application sur votre téléphone ?
Rempla'IDEL est une PWA, ce qui signifie qu'elle peut s'installer comme une vraie application sur votre smartphone, sans passer par un magasin d'applications.

Ouvrez le lien de l'application dans le navigateur Chrome ou Safari.
Sur Android (Chrome) : Cliquez sur le menu (les 3 petits points en haut à droite) et sélectionnez "Ajouter à l'écran d'accueil".
Sur iPhone (Safari) : Cliquez sur l'icône de partage (en bas de l'écran) et sélectionnez "Sur l'écran d'accueil".L'icône de Rempla'IDEL apparaîtra sur votre téléphone, et l'application s'ouvrira en plein écran !
🗂️ Les modules de l'application
1. 📊 Accueil (Dashboard)
Votre tableau de bord mensuel. Dès l'ouverture, vous retrouvez :

Vos KPIs (indicateurs clés) du mois : nombre de remplacements, revenus estimés, reste à percevoir, kilomètres, heures travaillées.
Alertes automatiques : Si un remplacement "En attente" ou "Facturé" date de plus de 30 jours, une bannière d'alerte apparaîtra pour vous prévenir de relancer le cabinet.
2. 📅 Planning
Gérez votre agenda avec 3 vues différentes : Mois, Semaine et Jour.

Glisser-déposer : Vous pouvez attraper un remplacement et le déplacer sur un autre jour pour le reprogrammer.
Copier-Coller (Nouveau !) :
Allez en vue Jour ou Semaine et cliquez sur "Copier jour".
Revenez en vue Mois ou Semaine. De petits boutons "Coller" apparaîtront sur chaque jour.
Cliquez sur "Coller" pour dupliquer instantanément votre journée (cabinet, horaires, et même la tournée de patients) sur un autre jour !
3. 🏥 Cabinets
Ajoutez vos cabinets de remplacement.

Attribuez-leur une couleur (elle sera utilisée dans le planning pour tout repérer d'un coup d'œil).
Renseignez l'adresse, le digicode, l'étage, le logiciel utilisé (utile pour vos futurs remplacements).
4. 🧑‍⚕️ Tournée & Patients (Suivi optionnel)
Vous ne voulez pas oublier un patient pendant votre journée ? Activez le suivi !

Dans le formulaire d'ajout d'un remplacement, cochez "Activer le suivi des patients".
Ajoutez vos patients (uniquement par Initiales pour la confidentialité, ex: "AB").
Renseignez le type de soin, l'heure prévue, et des notes privées.
Pendant votre tournée, ouvrez la Check-list Tournée (icône boussole) pour cocher les soins réalisés et voir votre barre de progression avancer !
5. 💶 Finances
Suivez l'aspect financier de votre activité :

Revenus estimés vs revenus reçus.
Répartition des revenus par cabinet (avec graphiques visuels).
Historique mensuel sur 12 mois.
6. 🚗 Kilométrage
Calculez automatiquement vos indemnités kilométriques annuelles.

Total des kilomètres parcourus sur l'année.
Indemnités estimées (basées sur le tarif kilométrique que vous avez défini dans les paramètres).
7. ⚙️ Réglages
Identité : Vos informations (Nom, RPPS, ADELI, IBAN).
Tarifs : Définissez votre tarif journalier et votre tarif kilométrique (ils seront pré-remplis automatiquement lors de la création d'un remplacement).
Types de soins : Personnalisez la liste déroulante des soins pour la tournée (ajoutez ou supprimez des soins selon votre pratique).
Données : Exportez une sauvegarde de vos données en format JSON.
💡 Astuces
Pas de réseau ? Pas de panique. L'application fonctionne parfaitement sans internet (dans les caves, les zones blanches, etc.). Les données se synchronisent dès que vous rouvrez l'app.
Couleurs : Associez une couleur spécifique à chaque cabinet dans l'onglet "Cabinets" pour visualiser votre semaine en un clin d'œil.
